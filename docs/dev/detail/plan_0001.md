# plan_0001 - GPT 모델 생성 확인 및 scripts/test_generation.py 검증

## User Requirements

- 현재 설정된 GPT 모델(또는 LLM 게이트웨이)을 통해 시나리오가 실제로 생성되는지 확인하고 싶음.
- `scripts/test_generation.py` 스크립트를 사용하여 생성을 시도하고 결과 확인.

## Goal

- `scripts/test_generation.py`를 실행하여 LLM 시나리오 생성 엔진의 엔드투엔드(E2E) 동작을 검증함.
- 생성된 시나리오 데이터의 구조적 무결성과 내용을 육안으로 확인.

## Scope

- In:
  - `scripts/test_generation.py` 실행 및 결과 분석.
  - LLM 게이트웨이 및 모델(`gpt-4o-mini` 또는 `gemini-2.0-flash-lite`) 연결 상태 확인.
- Out:
  - 생성된 시나리오의 DB 저장 로직 수정 (본 작업에서는 검증만 수행).
  - 새로운 에이전트 추가.

## Implementation Plan

- Step 1: 서비스 실행에 필요한 환경 변수 및 모델 설정 확인 (게이트웨이 URL, API Key 등).
- Step 2: 시나리오 서비스를 로컬에서 실행 (`bin/project run`).
- Step 3: `scripts/test_generation.py` 내의 포트 번호(`8030` vs `8040`) 정합성 확인 및 필요 시 수정.
- Step 4: `uv run scripts/test_generation.py`를 실행하여 시나리오 생성 요청.
- Step 5: 출력된 로그를 통해 액트, 시퀀스, 에셋(아이템, NPC 등)이 정상적으로 생성되었는지 검토.

## Unit Test Plan (must)

- What to test: `ScenarioEngine`의 기본 생성 로직 (Mocking 없이 실제 LLM 호출 테스트가 아니므로 유닛 테스트로는 스키마 검증 위주).
- Test cases:
  - Pydantic 모델이 LLM 응답을 정상적으로 파싱하는지 확인.
- Command:
  - uv run pytest tests/test_engine.py

## E2E Plan (must)

- Scenario: `scripts/test_generation.py`를 통한 "포스트 아포칼립스 마법 세계" 시나리오 생성.
- Expected:
  - HTTP 200 OK 응답.
  - JSON 응답 내에 `acts`, `sequences`, `entities` 등이 포함됨.
  - 터미널에 시나리오 내용이 정상적으로 출력됨.
- How to run:
  - `uv run scripts/test_generation.py`
- Validation:
  - 출력된 시퀀스의 개수가 3개 이상인지 확인.
  - 각 시퀀스에 `location_name`과 `goal`이 포함되어 있는지 확인.

- [ ] unit tests added/updated and passing
- [ ] e2e executed and passing (scripts/test_generation.py 성공)
- [ ] docs updated if needed
